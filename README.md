# Pulse

Монитор загрузки Mac в строке меню: CPU, GPU, память, диск, сеть и температура чипа.
Работает в фоне без значка в Dock, не требует прав администратора и ничего не отправляет в сеть.

## Строка меню

Четыре вида (Настройки → Строка меню → Вид), от широкого к узкому:

| Вид | Что показывает | Ширина, 4 метрики |
|---|---|---|
| Отдельно | каждая метрика — свой значок своего стиля (таблица ниже) | ~270 pt |
| Вместе | те же стили одним значком, без системных отступов | ~220 pt |
| **Сетка** (по умолчанию) | две строки «буква значение»: `C 37%  M 80%` / `G 5%  D 12M` | ~70 pt |
| Столбики | тонкая шкала на метрику, буква под ней | ~36 pt |

Буквы: C — процессор, G — графика, M — память, D — диск, N — сеть, T — температура.
На Mac с вырезом в экране лишние значки macOS просто прячет, поэтому по умолчанию стоит сетка.

Стили отдельных значков:

| Метрика | Виды |
|---|---|
| CPU | число · мини-график · шкала · кольцо · столбики по ядрам (E и P разделены) |
| GPU, память | число · мини-график · шкала · кольцо |
| Диск | скорость R/W · график чтения/записи · кольцо занятого места |
| Сеть | скорость ↓/↑ · график |
| Температура | число |

При высокой нагрузке значок подсвечивается (70% жёлтый, 85% оранжевый, 95% красный);
у памяти цвет зависит не от заполненности, а от давления памяти — на macOS полная память это норма.
Порядок значков меняется перетаскиванием с ⌘, правый клик — меню (панель, настройки, «Мониторинг системы», выход).

## Панель

Клик по значку открывает панель на вкладке этой метрики:

- **Обзор** — карточки всех метрик со спарклайнами, сведения о Mac.
- **CPU** — график пользователь/система, загрузка каждого ядра сейчас, тепловая карта ядер за период,
  средняя нагрузка, время работы, тепловой режим, топ процессов.
- **GPU** — загрузка, видеопамять, рендеринг/тайлер, число ядер GPU.
- **Память** — состав (приложения, зарезервированная, сжатая, кэш), давление, своп, история, топ процессов.
- **Диск** — скорость чтения/записи, тома с занятым местом, объём с момента загрузки, температура SSD.
- **Сеть** — входящий/исходящий трафик, интерфейсы с IP-адресами, объём с момента загрузки.

Графики показывают последние 1 мин / 5 мин / 15 мин / 1 ч; при наведении — значения всех рядов в этот момент.
История за час хранится в памяти и копится с момента запуска.

## Установка

```sh
scripts/install.sh        # собрать, положить в /Applications и запустить
scripts/build.sh          # только собрать build/Pulse.app
scripts/build.sh --universal   # arm64 + x86_64
```

Автозапуск включается в настройках («Запускать при входе в систему») или из терминала:

```sh
/Applications/Pulse.app/Contents/MacOS/Pulse --login-item on    # on | off | status
```

Требуется macOS 13+, Xcode Command Line Tools со Swift 5.9+.

## Устройство

- `Sources/PulseCore` — сбор данных без UI:
  - CPU — `host_processor_info` (тики по ядрам), типы ядер — из `IODeviceTree:/cpus` (`cluster-type`);
  - GPU — `PerformanceStatistics` у `IOAccelerator`;
  - память — `host_statistics64` в категориях «Мониторинга системы», давление — `kern.memorystatus_vm_pressure_level`;
  - диск — счётчики `IOBlockStorageDriver`, тома — `mountedVolumeURLs`;
  - сеть — 64-битные счётчики `NET_RT_IFLIST2` (en*, pdp_ip*; туннели не считаются, чтобы VPN не удваивал трафик);
  - температура — HID-датчики через приватный `IOHIDEventSystemClient` (ищется в рантайме; нет датчиков — нет температуры);
  - процессы — `/bin/ps` (он setuid и видит процессы всех пользователей), память своих процессов — physical footprint.
- `Sources/Pulse` — AppKit + SwiftUI: `StatusBarController` (значки и поповер), `MenuBarRenderer` (рисование значков),
  `Dashboard/*` (вкладки, Swift Charts), `SettingsView`, `LoginItem` (SMAppService, запасной вариант — LaunchAgent).
- Опрос идёт на фоновой очереди; процессы, тома и интерфейсы опрашиваются только пока панель открыта.

## Проверка

```sh
swift test                                           # ядро: математика, форматирование, история, реальный опрос
build/Pulse.app/Contents/MacOS/Pulse --snapshot out  # PNG всех значков, вкладок и настроек (светлая и тёмная тема)
```

`--snapshot` рисует всё вне экрана, не открывая окон и не трогая настройки; значения реальные, история за 15 минут
синтезируется вокруг них, чтобы на графиках было что показать.
